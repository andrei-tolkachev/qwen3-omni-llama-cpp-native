# Нативный голос Qwen3-Omni для llama.cpp

Независимое расширение для **Qwen3-Omni-30B-A3B-Instruct**: Talker, Code Predictor и Code2Wav на GPU, смешанное квантование Talker в Q4, потоковые текст и PCM, отмена генерации и управление видеопамятью.

**Сам llama.cpp, его сервер и GGML созданы авторами апстрима.** Andrei Tolkachev принадлежат только собственные доработки Omni и исходные ядра, выпущенные под MIT. Исходные лицензии и авторство апстрима сохранены. Разработка выполнена с помощью AI. Это не официальный выпуск ggml-org или Qwen.

[Сборка и запуск](README.md#build) · [Подробная инструкция, веса и API](tools/loraai_omni_native/README.md) · [Лицензии](LICENSING.md).

Релиз содержит два архива: полное дерево исходников с Omni и небольшой комплект переноса доработок в новую версию llama.cpp. Внутри одинаковый нативный модуль; рядом публикуются SHA-256. Веса моделей не включены. Перед переносом выполните `scripts/apply_to_llama.py --check`, затем соберите весь согласованный набор бинарников и библиотек.

Для длинных ответов используется `stream:true,audio_protocol:2`: текст передаётся сразу по дельтам, звук — порциями PCM. Пример `scripts/voice_client.py` воспроизводит поток через ffplay; Ctrl-C останавливает проигрывание и отправляет отмену. Нарезка текста на фразы реализована в самом нативном модуле.

Измерения относятся к Linux/CUDA/RTX 5090. Выбор устройства не привязан к названию видеокарты, но другие устройства ещё не квалифицированы. Проверен контекст 65 536; 128K не подтверждён. Смешанный Q4 Talker выбирается автоматически, когда найден соответствующий файл. У BF16 известен случай зависания CUDA-умножения; Q4 проходит этот вход, но причина BF16-дефекта не устранена.

В длинном тесте получено 600,97 секунды сегментированного PCM. Отдельный непрерывный 12-минутный тест без нарезки завершился с неразборчивой речью. Длительность сама по себе не доказывает качество: проверены ASR на нескольких русских фразах и отдельных фрагментах; широкая проверка на слух, английский и другое оборудование отсутствуют.

Сервер отказывается слушать внешний адрес без ключа API. Ключ проверяется и для генерации, и для отмены. Для удалённого доступа используйте TLS. Исторические нативные результаты — в [VALIDATION.json](tools/loraai_omni_native/VALIDATION.json); проверки подготовки этого выпуска — в [RELEASE_VALIDATION.json](RELEASE_VALIDATION.json).
